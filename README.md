Prueba

Descripción

Este proyecto consiste en la creación de una página web sencilla utilizando HTML y CSS.

Objetivos

Crear una estructura HTML básica.

Diseñar la página mediante CSS.

Aprender a crear y editar archivos desde GitHub.

Practicar el uso de commits para registrar los cambios.

Archivos del proyecto

index.html: contiene la estructura y el contenido de la página.

style.css: contiene los estilos visuales.

README.md: describe el proyecto y sus objetivos.
